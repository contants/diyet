API anahtarı nasıl alınır?
  1. console.anthropic.com adresinde hesap aç.
  2. Billing bölümünden kredi yükle (örneğin 5 $).
  3. Limits bölümünden aylık harcama sınırını 5 $ yap (ikinci güvenlik).
  4. API Keys → Create Key; anahtarı kopyalayıp buraya yapıştır.

Anahtar yalnızca bu telefonda saklanır, hiçbir yere yüklenmez. Fotoğraf yalnızca analiz için Anthropic'e gönderilir. Aylık sınıra gelince uygulama yeni analiz göndermez; yemekleri listeden eklemeye devam edebilirsin.

O saatten önceki 90 dakikada öğün eklediysen hatırlatma gelmez.
